    Publicação não configurada (modo local disponível)

    Para publicar, é preciso um token fino (fine-grained) do GitHub com permissão Contents: Read & write neste repositório. O token fica salvo somente neste navegador (localStorage) — nunca é enviado para outro lugar além da API do GitHub. Criar token →

    Dica: arquivos muito grandes (WAV longos) deixam o repositório pesado e a API do GitHub tem limite por arquivo. Para a web, prefira MP3 320 kbps. Mantenha os masters originais à parte.
